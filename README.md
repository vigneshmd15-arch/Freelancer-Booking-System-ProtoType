# Freelancer Availability Checking & Booking System

## Project Overview
A full-stack web application that allows users to view available freelancers, check their availability, and book appointments based on available time slots.

## Technologies Used

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- REST APIs

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Axios

### Database
- MySQL

## Features
- View available freelancers
- Check freelancer availability
- Select booking dates
- Display available time slots
- Book freelancer appointments
- Store booking details in MySQL

## Architecture
React.js → REST API → Spring Boot → MySQL

## How to Run

### Backend
1. Open the backend project.
2. Configure MySQL database credentials.
3. Run the Spring Boot application.

### Frontend
1. Navigate to the frontend folder.
2. Run `npm install`.
3. Run `npm run dev`.
